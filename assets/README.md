# Demo assets

- `site.json`: display names and the profile image path.
- `data/`: sample conversations, including opening triggers, a five-part Writing thread, and a folded Updates thread.
- `img/`: icon sprite, Norris’s photo, favicon, and a neutral profile placeholder.
- `fonts/`: optional fonts and their required license notices.
- `resume/`: a replaceable sample resume page.

To replace the profile image, put it in `img/` and update `portrait` in `site.json`.
The two legacy profile-image URLs resolve to that file. These assets work locally;
the demo does not download personal content or contact the live backend.
